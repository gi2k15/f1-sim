# Project Rules

## General

- Follow the existing code style and patterns.
- Use pnpm for running project commands.
- Keep code in JavaScript (ES Modules).

## Stack

- Framework: Vue 3 + Vite
- UI Library: Vuetify 4
- Enabled Features: Base setup
- Script language: Javascript

## UI & Component Guidelines

- Maximize the use of Vuetify components (`v-sheet`, `v-container`, `v-row`, `v-col`, `v-card`, `v-table`, `v-list`, `v-chip`, etc.).
- Avoid using plain `<div>` tags whenever a Vuetify component or utility can be used instead.
